 What is DOM?

 The DOM (Document Object Model) is a tree-like object representation of an HTML document created by the browser.

 It allows JavaScript to access, read, modify, add, and delete HTML elements dynamically after the webpage has loaded.

 Why do we need DOM?

 HTML is static. Once the browser displays the page, HTML alone cannot change its content.

 To make a webpage interactive (change text, colors, images, etc.), JavaScript needs a way to access HTML elements.

 The browser solves this by converting every HTML element into a JavaScript object. This collection of objects is called the DOM.

 # DOM Selectors

Selectors are used to access HTML elements.

getElementById()

Returns one element

const title = document.getElementById("title");
<h1 id="title">Hello</h1>
getElementsByClassName()

Returns HTMLCollection

const boxes = document.getElementsByClassName("box");
<div class="box"></div>
<div class="box"></div>
getElementsByTagName()

Returns HTMLCollection

const paragraphs = document.getElementsByTagName("p");
querySelector()

Returns first matching element

document.querySelector(".box");

document.querySelector("#title");

document.querySelector("p");

Works with CSS selectors.

querySelectorAll()

Returns NodeList

document.querySelectorAll(".box");

Returns every matching element.

DOM Selector Summary
Method	Returns
getElementById()	Single Element
getElementsByClassName()	HTMLCollection
getElementsByTagName()	HTMLCollection
querySelector()	First Matching Element
querySelectorAll()	NodeList

append()

appendChild()

Example

p.innerText = "Hello";

document.body.appendChild(p);
append() vs appendChild()
append()	appendChild()
Multiple elements	One element
Can append text	Element only
Modern	Older
insertBefore()

Example

Editing Elements
innerText

Only visible text

textContent

Returns all text

Hidden text included

innerHTML

Reads/Writes HTML

Creates actual HTML.
